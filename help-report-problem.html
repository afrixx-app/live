Report a problem

Use this page to prepare a clear report about a technical issue or content concern.

Back to SettingsReport a problem

What to include

Describe what you were trying to do, what happened, and the page where the problem occurred.

Helpful details

Include the device type, approximate time, and any exact error message. Do not include passwords or secret authentication codes.

Content concerns

For a video or comment concern, include the relevant creator or content details if available.

Submission status

This Help page is a guide only; it does not send a report to BIGULA. A verified support submission channel must be connected before reports can be sent.
